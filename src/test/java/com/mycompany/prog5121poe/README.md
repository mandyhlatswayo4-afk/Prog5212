# QuickChat Application

## Overview
QuickChat is a Java console-based messaging application developed for the PROG5212 programming project.

## Features
- Send messages to recipients.
- Validate recipient phone numbers.
- Generate unique message IDs.
- Generate message hashes.
- Display sent message details.
- Store messages in a JSON file.
- Run unit tests using JUnit.

## Technologies Used
- Java
- Maven
- NetBeans IDE
- JUnit 5
- GitHub

## How to Run
1. Open the project in NetBeans.
2. Build the Maven project.
3. Run the PROG5121POE class.
4. Follow the console menu instructions.

## Testing
JUnit tests are included in the project to test message IDs, phone number validation, message hashes, sending messages, and storing messages.
